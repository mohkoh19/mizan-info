# Mizan information site

Small static information site for the private Mizan planning pilot. It is published from a separate repository and contains no framework code, private planning records, credentials, or OAuth secrets.

The site currently uses the repository path `/mizan-info/` on GitHub Pages. Replace the path-based links in the three HTML files when configuring a custom-domain root, then configure the DNS name and verify it before entering it as an authorized domain in Google Cloud.

The privacy notice intentionally describes Google OAuth as test-only and does not claim production access or verification. Before a production submission, reconcile this notice against the exact OAuth scopes, effective host/model providers, retention, and support contact configured for the pilot.
